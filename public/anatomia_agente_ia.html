Cómo piensa, percibe, recuerda, decide y actúa.

DESLIZA PARA EXPLORAR

01 · Punto de partida

¿Qué es un agente?

CHATBOT
Entrada→Modelo→Respuesta→Fin
WORKFLOW · RUTA FIJA
Trigger→Paso A→Paso B→Paso C→Fin
AGENTE · ELIGE LA RUTA

Un workflow sigue una ruta.

Un agente decide qué ruta tomar.

02 · Modo escaneo anatómico

Anatomía
de un agente

Cada sistema del agente, representado como una parte del cuerpo.

Selecciona un punto para acercar la cámara.

Vista explosionada: carcasa → estructura interna → columna → corazón → sistema nervioso.

03 · Cabeza

El cerebro:
el modelo (LLM)

Interpreta el lenguaje, razona y ayuda a decidir.

MODELO ≠ AGENTE

El modelo es solo una parte del agente.

El agente es el sistema construido alrededor del modelo.

04 · Núcleo del cerebro

System Prompt

La especificación operativa del agente.

  1. 01IDENTIDAD
  2. 05HERRAMIENTAS
  3. 02OBJETIVO
  4. 06CRITERIOS DE DECISIÓN
  5. 03CONTEXTO
  6. 07ESCALAMIENTO
  7. 04REGLAS
  8. 08CONDICIÓN DE PARADA

PROMPT DEFICIENTE 15 % del cerebro activo

Eres un agente de atención al cliente.
Ayuda a los usuarios.

PROMPT OPERATIVO 100 % del cerebro activo

IDENTIDAD      Eres agente de atención de NovaShop.
OBJETIVO       Resolver solicitudes sobre pedidos.
TOOLS          consultar_pedido · crear_ticket · enviar_email
REGLAS         Nunca inventar el estado de un pedido.
ESCALAMIENTO   Escalar disputas de pago.
STOP           Terminar cuando la solicitud quede resuelta.

05 · Brazos y manos

Tools

Capacidades para actuar sobre el mundo.

SOLICITUD→LLAMADA A TOOL→GMAIL→RESULTADO

Un LLM puede generar información.

Un agente con Tools puede actuar.

06 · Destreza de las manos

Skills

Conocimiento procedimental reutilizable.

TOOLSKILL MartilloSaber construir una mesa GmailCómo responder bien una reclamación Navegador webCómo investigar una empresa Hoja de cálculoCómo analizar un estado financiero
SKILL CARGADA · 1/3LISTO PARA EJECUTAR

Una Tool permite hacer algo.

Una Skill enseña cómo hacerlo correctamente.

07 · Ojos y sensores

Contexto

Lo que el agente puede percibir ahora.

Mensaje actual+Estado del sistema+Documentos+Resultados de tools

Si no está en el contexto, el agente no lo ve.

08 · Módulo de memoria

Memoria

Lo que el agente conserva entre pasos y conversaciones.

Cliente
Carlos Mendoza
Pedido
#18492
Problema
Producto dañado
Historial
3 compras

Sin memoria, cada interacción comienza desde cero.

09 · Corazón

Objetivo

Atender correctamente al cliente.

El objetivo organiza todas las decisiones.

Es lo que mantiene activo al agente hasta cumplirlo.

10 · Columna vertebral

Guardrails

Políticas y restricciones que definen los límites.

ACCESO DENEGADO

SE REQUIERE APROBACIÓN HUMANA

Acción bloqueada: realizar un pago sin autorización.

11 · Sistema nervioso

Loop del agente

PERCIBIR→DECIDIR→ACTUAR→OBSERVAR→VOLVER A DECIDIR

Se repite hasta cumplir el objetivo o alcanzar una condición de parada.

13 · La anatomía completa

Todo junto

  • El modelo es el cerebro.
  • El system prompt define el puesto.
  • Las tools son sus manos.
  • Las skills son sus procedimientos.
  • La memoria conserva información.
  • El contexto le permite percibir.
  • Los guardrails definen sus límites.
  • El loop le permite decidir, actuar y corregir.
